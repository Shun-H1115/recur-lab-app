# RECUR — 漸化式ラボ

Rust / eguiで作成した、Windows向けネイティブデスクトップアプリです。WebViewやブラウザーは使いません。実行時の外部通信・アカウント登録はありません。

## 起動

配布版は `dist/recur-lab.exe` をダブルクリックしてください。Rustのインストールは不要です。OpenGL 3.3を利用できるWindows環境が必要です。

ソースから起動する場合:

```powershell
cargo run --release --locked
```

`rust-toolchain.toml` でRust 1.88.0を指定しています。WindowsでのビルドにはVisual Studio C++ Build ToolsとWindows SDKが必要です。既定のRustツールチェーンは変更しません。

## 可視化する式

| モード | 式 | 表示する状態 |
| --- | --- | --- |
| 三項 | `a[n+2] = p*a[n+1] + q*a[n]` | `(a[n], a[n+1])` |
| 四項 | `a[n+3] = p*a[n+2] + q*a[n+1] + r*a[n]` | `(a[n], a[n+1], a[n+2])` の3D投影 |
| 線形連立 | `x[n+1] = m11*x[n] + m12*y[n]`, `y[n+1] = m21*x[n] + m22*y[n]` | `(x[n], y[n])` |

- 係数スライダーと数値入力で即座に再計算します。三項・四項の係数は±8まで直接入力できます。連立行列の要素は±3です。
- 三項・四項では右上の特性根をドラッグできます。実係数を保つため、複素根は共役のペアで動きます。実根を上下に動かすと別の実根とペアになります。連立モードの固有値は表示のみです。
- 7種類のプリセット: 渦巻き、収束、鞍点、周期、銀河、三つの実根、放射。
- 粒子数、軌跡長、更新速度、初期分布、明るさ、配色、発光、座標軸を変更できます。
- 金色の単独軌道は、ユーザーが指定した初期値から反復します。整数ステップを点で表示します。

## 操作

| 操作 | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| 右矢印 | 一時停止して1ステップ進める |
| R | 粒子とステップ数をリセット |
| H | 鑑賞モード（操作パネルを隠す） |
| F11 | 全画面の切り替え |
| Esc | 全画面・鑑賞モードを解除 |
| 2Dでドラッグ | 移動 |
| 3Dでドラッグ | 回転 |
| 3DでShift + ドラッグ | 移動 |
| ホイール | 拡大・縮小 |
| ダブルクリック | 移動とズームをリセット |

操作パネルは縦にスクロールできます。画面が小さい場合は下へスクロールすると初期値、視点、保存ボタンが表示されます。

## 保存

実行ファイルと同じディレクトリに `output/` を作成します。配布版なら `dist/output/`、`cargo run --release` なら `target/release/output/` です。

- **設定を保存 / 読み込み**: `settings.json`。係数、初期値、表示設定を保存します。読み込み時に型・範囲・ファイルサイズを検証します。再保存時はこのファイルを上書きします。
- **PNG保存**: ウィンドウの表示内容を `recur-<timestamp>.png` に保存します。
- **CSV**: 指定した初期値からの単独軌道を `orbit-<timestamp>.csv` に保存します。三項の場合、未使用の第3座標列は空欄です。連立の場合は `n,x_n,y_n` です。

書き込み権限のあるフォルダーに実行ファイルを置いてください。

## 数学上の注意

`rho`（ρ）は特性根の絶対値の最大値です。すべての根が単位円内なら、すべての初期値が原点へ収束します。単位円の外に根がある場合、発散するモードがありますが、特殊な初期値では発散しない場合があります。単位円上の根がある境界では、重根や初期値も関係します。

多数の粒子を継続して観察できるよう、遠方・原点付近・180項経過の粒子は初期分布に戻します。金色の単独軌道とCSVはこの再配置を行いません。計算が非有限値、または絶対値 `1e100` を超える場合は単独軌道を打ち切ります。

点が数列の離散的な値で、線と移動する先端はその線形補間です。連続時間の微分方程式の解を描いているわけではありません。3Dは正射影です。特性根は浮動小数点による解析式で、非常に近接した根の表示には丸め誤差があります。

## 開発・検証

```powershell
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

コード構成:

- `src/math.rs`: 漸化式、特性根、Vietaの公式、安定性。
- `src/simulation.rs`: 粒子群、補間、単独軌道。
- `src/app.rs`: 日本語UI、3D投影、発光描画、保存と入力検証。

日本語フォントはOSに導入済みのメイリオなどを読み込みます。フォントファイル自体は同梱していません。動作確認の対象はWindowsです。macOS / Linuxの実機検証は行っていません。
